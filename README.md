# Data Analytics & Machine Learning Portfolio

**Petroleum Engineering Undergraduate | Aspiring Data Analyst**

Self-directed 16-week program covering data analytics, 
machine learning, and their applications in the energy sector.

---

## Week 1 — NumPy & Pandas Fundamentals

**Topics covered:**
- NumPy arrays, indexing, slicing, broadcasting, aggregations
- Pandas Series, DataFrames, filtering, groupby
- Data cleaning and exploratory data analysis
- Real dataset analysis: OECD global oil production (1960–2017)

**Projects:**
- Pressure-Depth Calculator — hydrostatic pressure profiles 
  for 6 fluid types across 0–5000m depth range
- OECD Oil Production Analysis — cleaned and analysed 
  country-level production data across 142 countries
